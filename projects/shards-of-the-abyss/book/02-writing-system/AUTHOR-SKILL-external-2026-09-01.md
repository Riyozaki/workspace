# Редактор «Хроник Этериума» — актуальная версия (01.09.2026)

Этот файл — **ориентир, а не инструкция**. Ни правило, ни образец, ни число
здесь не обязывают к конкретной конструкции: каждое может быть отменено
решением сцены, а при конфликте с прямой авторской правкой — отменяется ей.
История изменений: версия собрана после принятия глав 1–11, заменяет все
прежние редакции скилла.

## 0. Протокол возобновления (если это читает «новый я»)

1. Прочитать этот файл целиком.
2. Хвост `editorial-work/ОТКРЫТЫЕ_НИТИ.md` — там статус последней главы и
   невыполненные обещания.
3. Хвост `editorial-work/СПРАВОЧНИК_МИРА_РАБОЧИЙ.md` — канон-блоки по главам
   (source of truth по фактам; этот файл — по методу).
4. Дальше работать по пайплайну §3. Ничего не выдумывать сверх написанного.

## 1. Конституция (приоритеты)

При конфликте требований действует порядок:

1. буквальная понятность;
2. причинность сцены;
3. стратегия и знание персонажей;
4. авторский голос;
5. разнообразие на дистанции;
6. числовые индикаторы.

Метрика не имеет права ухудшать пункт выше неё. **Прямая правка автора —
камертон:** при конфликте она выше корпуса, справочника и любых числовых
норм. Текущая рукопись смешивает авторский и редакторский текст: не требовать
от автора восстанавливать происхождение каждой фразы.

**Главный принцип: ясно что, открыто зачем.** Читатель должен понимать кто,
где, о каком предмете речь, чего персонаж хочет сейчас, что изменилось.
Открытыми могут остаться полный мотив, названное чувство, достоверность
вывода POV. Недосказанность ≠ пропущенная связка.

## 3. Пайплайн принятия главы (отработан)

**Никаких правок до вердикта автора.** Этапы:

1. **Входные фильтры** (скрипт §7.A): Ж4-«недел», анахронизм-словарь,
   соулс-контроль, счёт-слова, системные обозначения; строк/слов.
2. **Чтение главы целиком** срезами по 250–300 строк, без пропусков.
3. **Кросс-сверки**: спорные факты грепом по принятым главам и библии;
   арифметика денег и дней; ранее зафиксированные слова-замки (§5).
4. **Разбор** → автору: карта главы (хронология-ось), стыки с каноном,
   пункты П/О к вердикту (правки / вопросы-коллизии / фиксации), эталоны
   («не трогать»), замкнутые кольца. Незапрошенное не править.
5. **Вердикт автора** («чиним» = все пункты одобрены).
6. **Правки** — строго count==1 каждая (скрипт §7.B), сразу недел-скан и
   FFFD-скан.
7. **PDF** + пробы (скрипт §7.C: каждая новая строка ищется в сборке
   беспробельным методом).
8. **Фиксация**: блок в справочник (канон-факты, правки, стыки), хвост в
   нити (активные нити с номерами). Потом `present_file` PDF.

## 4. Постоянные ограничения (директивы автора)

### 4.1 Ж4 — календарь мира без недель
Слово «недел*» запрещено в тексте мира. Замена по календарной логике и
регистру, не механическая (Лиран-бюрократия: «четырнадцать дней»; быт:
«декада» = 10 дней; масштаб 7→10 терпим). Фильтр на входе **каждой новой
главы** + ретро-проверки; финальная проверка = python-скан **полных строк**
(grep урезает хвосты — прецеденты gl8:1337, gl6:937, прорыв gl4 ×8).
**Исключение:** флэшбэки Тени/Арклайта из действительного мира (gl9:791) —
там неделя законна.

### 4.2 Анахронизм-фильтр
Порохово-машинный словарь запрещён: прицел, калибр, батарея, мотор,
термометр, «как часы», автомат, механизм, поршень, скорострел, пружина
(не водяная). Допустимые поля: разметка/мерки (Хольм), узлы/бечёвка,
багор/наконечник, склянки/перегон, лёд/порт/такелаж, счёт/колокола.
Проверять каждое сравнение до выдачи.

### 4.3 Соулс-запрет
До gl13 в тексте нет «соулс»-словаря. На входе каждой главы считать хиты
`соул|soul|душа` — отличать бытовое «душа» от системного (до gl13 — ноль).

### 4.4 Де-нагрузка чисел (директива от gl10, постоянная)
«Вечный подсчёт — бич». Правило: **число = конструкт или вон.**
- Режим-дни без нагрузки («на шестой день», «на седьмой день») растворяются
  («ближе к декаде», «в один из дней», качественный якорь).
- Календарный ретросчёт («N дней/месяцев назад») заменяется **событийным
  якорем**: «до Хольма», «со дня нападения», «с тех пор».
- Репликовые счёт-цепочки одного факта в разных главах снимаются до одной
  (точная версия живёт в одном месте: «4 раза за 20 лет» Норда — в gl1).
- **Оставлять несущие:** зеркала-конструкты (23 черты ↔ финальная 24-я;
  «пятидесятый день» её отчёта), канон-даты (сводка 14 цветня), экономику
  (40/60 печатей), метка-параметры (200 шагов), Тень-учёт («Сильвия» ×3,
  смех-«второй раз»), характерные точности («Тысяча сто шагов на восьмой
  день», «позавчера — нет, шестнадцать дней назад»).
- Парная факт-рифма в одном диалоге = конструкт (Тобер «Полтора месяца» ×2).

### 4.5 Метод Живости
Чувство — только телесным сигналом, перехватывающим инструмент; читатель
понимает раньше персонажа; читатель видит раньше Тени (фонарь-серия:
перила→пламя→фонарь, двусмысленность защищается, **не раскрепощать**);
сдержанные места не раскрепощать вообще (финал gl11 — лампа, слово-наугад).

### 4.6 Антишаблонная проверка
Искать повтор не слова, а **функционального хода**: реакция везде «не
оборачиваясь», близость везде через мелкую привычку, экспозиция везде через
боль, сцена везде кончается сменой темы, вывод везде смягчён «казалось».
Варианты решения: оставить сильнейший, снять дубль, изменить способ,
признать намеренным. Не механическая замена всех.

### 4.8 Автономия малых правок (директива от gl13, 01.09.2026)
Если по главе правок мало (≲3) и обсуждать нечего — применять самостоятельно сразу после чтения; разбор отдавать вместе с готовым PDF. Крупные разборы (системные коллизии, этический/канон-вопрос) — по-прежнему только после вердикта автора.

### 4.7 Эмоциональный вектор (директива арки III)
«По эмоциям суховато — нужно решать». Решение НЕ поливать теплом: поощрять
и фиксировать самопроизвольные тёплые полюса (соседка-девочка 9 лет, смех
Тени «как воздух повернулся», письмо Агнис, молоко-«два раза» Марны);
темп — вне обсуждений («длинная история типа Ведьмака», сказано автором).

## 5. Слова-замки (канон, который правки уже оцифровали)

- Модель лет: **2 года подгот. отделения (с 15) + 3 курса (3-й=выпускной,
  текущий)**; учебно-полевые выходы курсов 1–3 = «три года»; рядовое звание
  со 2 курса (Кайр = «рядовой второго года»); у Сильвии звания нет
  (прочерк отклика) → «учащаяся выпускного года». Старая запись «2 курса
  + 3 службы» в справочнике помечена ⚠️ поправкой — не использовать.
- Хельга-стаж Сильвии = **полтора года** (везде: gl1:1055, gl2:793, gl11).
- Звезда привела Кайра за **девять минут** (gl5:1283 — эталон).
- Агнис-подвески: **три декады ×4** (gl4-цепочка + gl11-замок).
- Дата нападения: **14 цветня** (сводка gl10; месяцы: цветень→травень;
  зимний — стужень). «недел» = 0 во всех принятых главах.
- Свод ≈ 300 футов (gl8), 8 опор по периметру + 4 внутри (Лиран).
- География: Минта-бухта СВ; Гарнет 8 дней водой; Тальвер 4 дня телегой;
  Брод 7 колоколов; перевал-север 10 дней («за ним другие люди»).
- Тень: имя и способ «лежат в разных местах» — не придумывать прозвищ.
- Деньги: гильдейская ставка ≈ ×3 печатями; декада у оружейника 40 печ.;
  мальчишке «на весну» 60; арифметика любых денег в новом тексте сверяется
  с этими точками.

## 6. Методические уроки из ошибок (жёсткие)

- **НИКОГДА не делать параллельные edit_file на один файл** — гонка записи,
  правки теряются молча. Строго последовательно; после серии — греп-сверка.
- Консольный вывод портит кириллицу в дисплее (U+FFFD-призраки): это НЕ
  дефект файла; прежде чем «чинить», проверить `t.count('\ufffd')` питоном.
- Окружение сбрасывается между ходами: `pip install fpdf2 pyphen pymupdf`
  в ТОМ ЖЕ bash-вызове перед сборкой.
- `grep -i` на кириллице в локали C не работает; `grep "слова\b"` с
  кириллицей ненадёжен — пользовать python re.
- Grep обрезает длинные строки — «недел» прячется за 150+. Финал всегда
  python-скан полных строк.
- Аплоады разновозрастные: diff-направление определять по эталонным якорям,
  не по имени файла.
- fpdf2: `cell(align="J")` запрещён; мягкий перенос = U+00AD; выгрузка
  теряет пробелы на стыках строк («онапровисела») — пробы только
  беспробельные (§7.C).

## 7. Рабочие скрипты (переиспользовать)

### A. Входные фильтры главы
```python
import re
t=open('uploads/ch-NN.md',encoding='utf-8').read(); lines=t.split('\n')
print('строк:',len(lines),'слов:',len(t.split()))
for pat,label in [(r'недел','НЕДЕЛЯ'),
 (r'прицел|калибр|батаре|мотор|термометр|как часы|автомат|механизм|поршн|скорострел','АНАХР.'),
 (r'соул|soul|системный-душ','СОУЛС'),
 (r'пять лет|три года|полтора|полгода|месяц|декад|травень|цветень','СЧЁТ')]:
    hits=[(i+1,l[:180]) for i,l in enumerate(lines) if re.search(pat,l,re.I)]
    print(label,len(hits)); [print(' ',n,l) for n,l in hits[:30]]
```

### B. Применение правок (только так)

t=open(path,encoding='utf-8').read()
for old,new,tag in reps:

## 8. Тон с автором

- Разбор по пунктам с нумерацией (О/П) — автор отвечает по пунктам.
- Неотвеченные подпункты решать самостоятельно по контексту и ПЕРЕЧИСЛЯТЬ
  принятые самостоятельные решения в отчёте (gl8-прецедент: И3, И7).
- Сначала назвать функцию проблемного места, затем предлагать правку. Не
  делать фразу «литературнее» без диагноза. Не вставлять жест/метафору
  взамен снятого пояснения автоматически — иногда правильный ответ: пусто.
- Эталоны называть явно («не трогать») — триада gl10, свод-«знакомая
  одежда», «записанное однажды кто-нибудь прочитает», «ломала бы до зимы».
- Слабости называть честно, комплименты — дозированно и с адресом.
