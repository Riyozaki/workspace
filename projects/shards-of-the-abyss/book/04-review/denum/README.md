## Что снято (типы)
- возраст персонажей числом («лет пятидесяти», «лет сорок пять», «лет двадцать пять», «ему шестьдесят один») → «немолодой», «старик», «немногим старше меня», «в годах», «моих лет» — или просто описание без возраста;
- расстояния в шагах/локтях/ладонях там, где не ремесло («в трёх шагах», «через сорок шагов», «шагов десять на пятнадцать», «два локтя») → «поодаль», «чуть дальше», «рукой подать», «всего ничего»;
- время в минутах/секундах/полуколоколах («минут двадцать», «секунд десять», «полсекунды», «полколокола») → «долго», «постояла», «помолчала», «один вдох», «не сразу»;
- стаж/сроки в годах («двадцать девять лет», «три года», «пять лет», «двадцать два года», «четырнадцать лет») → «всю жизнь», «за всё время», «годами», «полжизни», «давно», «с детства»;
- счёт дней с нападения (гл. 8 «семнадцать дней» ×8 → оставлен ×2, остальное «всё это время»; «пять дней» → «все эти дни»);
- статистика в репликах взрослых (Ирвин «29 лет / 4 случая / 3 из них…» → «за всё время… считаные разы… тот один и не выжил»; «тридцать в набор, десять доходят» → «горстка, доходит треть»; Ирсаль «1 из 30 / 1 из 7 / четыреста проб» → «редкость / через дом / каждый день»).
