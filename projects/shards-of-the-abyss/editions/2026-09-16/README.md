## Повторная сборка

Из корня репозитория, в отдельном виртуальном окружении:

```bash
python -m venv .venv
.venv/bin/pip install -r projects/shards-of-the-abyss/editions/2026-09-16/tools/requirements.txt
python projects/shards-of-the-abyss/editions/2026-09-16/tools/rebuild.py
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-16/tools/typeset.py
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-16/tools/check_pdf.py
```

`rebuild.py` проверяет хэши источников и каждую точную замену; расходящийся с рецептом существующий Markdown не перезаписывает. Перед изменением рецепта сохранить самостоятельные новые правки. `typeset.py` пересоздаёт PDF, `check_pdf.py` — протокол PDF. Виртуальное окружение и промежуточные изображения не добавлять в Git.

Шрифты приложены вместе с лицензией. Чтение PDF не требует Python или установки шрифтов. Подготовка для конкретной типографии — отдельный этап; параметры печати, обложка и выходные сведения здесь не назначены.
