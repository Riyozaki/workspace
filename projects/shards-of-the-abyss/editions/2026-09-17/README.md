## Воспроизведение

Из корня репозитория, с зависимостями из `tools/requirements.txt`:

```bash
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-17/tools/build.py
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-17/tools/check_docx.py
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-17/tools/typeset.py
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-17/tools/check_pdf.py
.venv/bin/python projects/shards-of-the-abyss/editions/2026-09-17/tools/check_delivery.py
```

Сначала проверяется неизменность базы и предыдущих сгенерированных файлов. Художественные исправления вносить через журнал, не поверх готовых файлов: сборщик намеренно откажется затирать ручную правку. После изменения прозы обновить выбранные сравнения. PDF использует сохранённые шрифты и лицензию из соседней редакции16.09. Скрипты разовых правок из `.cache` повторно не запускать.
