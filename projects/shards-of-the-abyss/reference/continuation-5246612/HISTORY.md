# Как шла работа (08–11.09.2026, прежний агент)

Восстановлено по двум фрагментам диалога (`legacy/dialog-*.txt`) и коммитам.

## Метод, который сложился
1. Агент читает арку целиком, критично, с журналом замечаний → обсуждение с автором → согласованное направление.
2. Проба на одной сцене (мастерская Норда) → «на уровень» → широкая переработка.
3. Дальше главы выдаются по одной: **цельный файл + две пары «было/стало» в чате**. Автор целиком не перечитывает — оценивает по парам и точечно уточняет.
4. Автор вмешивается редко и коротко: «отлично, продолжаем» / конкретная претензия («дрянь» — не слово Агнис; сцена репетиции непонятна; «не…, а…»; «костяшки»; «мало жести»). Агент правит и закрепляет правило.
5. После арки — обзор событий и мнение агента; иногда перестройка (вторая арка → разведка на Юге по идее автора).
