## Откуда берутся +250 тысяч строк

Сравнение текущей ветки с исходным коммитом этой сессии `53a742e17d8f10845b37f938253529c8382d6d48`:

|---|---:|

У накопительного diff и чистоты рабочей папки разные базы: все файлы могут быть давно закоммичены, но по сравнению с началом сессии они всё равно новые. Очередной commit сам по себе такой diff не обнуляет.

Преобладает импорт исходников и архивов, а не последние изменения главы. Такой объём — правдоподобный фактор тяжёлой загрузки/отрисовки. **Не доказано**, что именно он объясняет задержки сообщений и страницы: нет доступа к browser Performance/Network и внутренней реализации Arena.

## Выполненное безопасное изменение

Добавлен корневой `.gitattributes` с `-diff` только для:

1. `projects/shards-of-the-abyss/book/**` — неизменяемый импорт.
2. `projects/shards-of-the-abyss/review/*.json` — машинные отчёты, журналы и точные копии сравнений; человекочитаемые Markdown-версии остаются обычным текстом.
3. `projects/shards-of-the-abyss/drafts/arc-02/arc-02-v3.md` — сборник, дублирующий отдельные главы.

Это стандартное правило Git: **не разворачивать содержимое этих путей в текстовый diff**. Файлы остаются отслеживаемыми, доступны для чтения, скачивания и проверок. Их содержимое не изменено. Индивидуальные главы, редакторские заметки Markdown, инструменты и инструкции сохраняют обычный текстовый diff.

### Измеренный эффект на прежнем HEAD

Оба измерения сравнивают одну пару коммитов: начало сессии и `bde7cd56f21fee7e03dd9431c0bc420e0c458956`. Во втором применены новые атрибуты из рабочего дерева.

- Обычный текстовый diff: **21 487 635 → 2 986 147 байт**, уменьшение **86,1%**.
- Добавленные текстовые строки: **254 599 → 30 691**.
- Построение нового обычного diff: около **0,129 с**.
- 437 файлов представлены без текстового разворачивания, включая ранее двоичные файлы.
- `git check-attr` подтвердил: у новой 17 и её Markdown-передачи обычный diff, у выбранных технических/импортированных файлов он отключён.
- Перед введением правил сохранены SHA256 всех **531 отслеживаемого файла**; сразу после изменения каждый файл повторно сверён — содержимое всех совпало. Для записи текущей диагностики позднее добавлена отдельная заметка в NOW; проза/источники/исторические QA не менялись.

**Важное ограничение:** Arena может строить/кэшировать diff своим способом, игнорировать `.gitattributes` или принудительно трактовать всё как текст. В таком случае локальный результат не уменьшит панель Arena. Этого проверить из sandbox нельзя. Числа выше — результат Git, не обещание такого же счётчика в UI.

## Что не делалось

- Не удалялись файлы рукописи, исходники, архивы, история Git или временные материалы книги.
- Не применялись merge, reset, rebase, force-push, смена/создание ветки.
- Не перезапускалась среда, не завершались системные процессы.
- Не очищались данные сайта, cookies, история браузера или чат; настройки сессии не менялись.
- Не выполнялась ненужная сборка мусора Git: репозиторий уже маленький и работает быстро.

У агента нет доступа к хранилищу самой переписки и средствам её резервного копирования или удаления. Git сохраняет рабочие материалы, но не является экспортом всего чата.

## Что проверить в интерфейсе

После завершения ответа один раз обновить страницу, не очищая данные сайта, и по возможности держать Diff закрытым. Если счётчик всё ещё около +250 тыс., правила могли быть проигнорированы или UI показывает старый кэш. Если счётчик уменьшился, но задержки остались, большой текстовый diff не был единственной причиной.

Если улучшения нет, для поддержки Arena полезны данные этого отчёта: рабочая среда свободна, `git diff` занимает доли секунды, исходный накопительный текстовый diff — 21,5 МБ/254,6 тыс. строк, оптимизированный Git diff — 3,0 МБ/30,7 тыс. строк. Можно **спросить**, доступна ли смена базы накопительного diff на текущий HEAD либо отключение его автозагрузки **без новой сессии и удаления чата**. Наличие такой функции не подтверждено, выполнить её инструментами репозитория нельзя.

## Обратимость

Чтобы вернуть прежний показ diff, достаточно удалить три правила `-diff` из `.gitattributes` обычной правкой файла. Историю переписывать не нужно.

Для разового сравнения отдельного скрытого пути можно принудительно включить текст:

```bash
git diff --text 53a742e17d8f10845b37f938253529c8382d6d48 HEAD -- projects/shards-of-the-abyss/book/03-manuscript/arc-03/ch-17.md
```

Не запускать `--text` на весь репозиторий ради оптимизации: это заставит Git выводить даже PDF/PNG как текст и увеличит результат. Саму книгу продолжать читать из файлов; новые 1–17, стык 17→18 и все авторские решения остаются на месте.
