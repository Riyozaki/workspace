# 🚲 Пеликан на велосипеде (SVG)

Векторная иллюстрация «пеликан на велосипеде», нарисованная кодом, без генеративных моделей.

## Файлы

| Файл | Что это |
| --- | --- |
| `pelican-on-bicycle.svg` | Итоговая иллюстрация со сценой: дорога, солнце, тень, линии скорости |
| `pelican-on-bicycle.transparent.svg` | Только пеликан и велосипед, фон прозрачный (для вставки куда угодно) |
| `build_svg.py` | Генератор обоих SVG: спицы/геометрия рамы считаются кодом, перья и клюв — кривые Безье |
| `index.html` | Страница-витрина с предпросмотром и кнопками «Скачать» |
| `preview.png`, `preview-transparent.png` | Растровые превью для быстрого просмотра |

## Как пересобрать

```bash
python3 build_svg.py   # перезапишет оба svg
```

## Детали реализации

- `viewBox="0 0 1000 700"`, масштабируется без потерь; есть `<title>`/`<desc>` и `role="img"` для доступности.
- Колёса: покрышка — кольцо (stroke), спицы генерируются циклом (`spokes()`), поэтому оба колеса идеально симметричны.
- Порядок слоёв: дальний шатун → дальняя лапа → рама → трансмиссия → седло → хвост → тело →
  голова/шея/клюв → крыло → ближняя лапа → ближний шатун (лапы стоят на педалях, крыло держит руль).
- Палитра собрана в словаре `C` в начале `build_svg.py` — перекрасить можно за одну правку.
