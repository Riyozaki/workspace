# Пеликан на велосипеде 🚲🐦

Векторная иллюстрация на тему классического теста «pelican on a bicycle».

| Файл | Назначение |
| --- | --- |
| `pelican-on-bicycle.svg` | готовая иллюстрация (900×650, самодостаточный SVG: градиенты, `title`/`desc` для доступности) |
| `gen_svg.py` | генератор: вся геометрия (спицы, касательные цепи, педали по углу шатуна) считается кодом — правится числами, а не «на глаз» |
| `preview.png` | растровый предпросмотр для быстрого просмотра |

## Что внутри рисунка

- **Пеликан**: единый бесшовный силуэт «туловище + шея + голова», сложенное крыло с перьями,
  хвост-веер, длинный клюв с горловым мешком и крючком на кончике, перепончатые лапы на педалях.
  Пасхалка: в горловом мешке полупрозрачным силуэтом плывет рыбка.
- **Велосипед**: ромовидная рама с контуром, спицованные колёса (16 спиц), вилка, руль с звонком,
  седло, шатуны под 45°, цепь построена по внешним касательным к ведущей звёздочке и трещотке.
- **Сцена**: небо с градиентом, облака, солнце, дорога, тени под колёсами и линии движения.

## Перегенерация

```bash
python3 gen_svg.py            # пересоздаёт pelican-on-bicycle.svg
```
