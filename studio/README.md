# Studio

Собственная реализация небольшой студии для сцен, источников, записи и трансляции
(аналог базового набора OBS Studio). Код написан с нуля; идеи взяты из общей практики
таких программ, код оригинала не использовался.

Подробный отчёт о том, что сделано и что проверено: [`../docs/REPORT.md`](../docs/REPORT.md).

## Требования

- Node.js 18+ (проверено на 22.22.3)
- ffmpeg для записи и трансляции. Укажите путь переменной `STUDIO_FFMPEG`
  или поставьте `ffmpeg` в `PATH`. Без ffmpeg предпросмотр работает, запись/стрим отвечают
  понятной ошибкой.

## Запуск

```bash
npm install
STUDIO_FFMPEG=/путь/к/ffmpeg npm start -- --port=8080 --project=projects/demo.json
# открыть http://localhost:8080
```

Параметры (флаг или переменная окружения):

| Флаг | Переменная | По умолчанию | Смысл |
|---|---|---|---|
| `--port` | `PORT` | 8080 | порт HTTP |
| `--host` | `STUDIO_HOST` | `127.0.0.1` | адрес привязки. `0.0.0.0` открывает API в сеть без авторизации |
| `--project` | `STUDIO_PROJECT` | `projects/default.json` | файл проекта (если нет — создаётся пустой) |
| `--out` | `STUDIO_OUTPUT` | `recordings/` | папка записей |
| — | `STUDIO_FFMPEG` | `ffmpeg` | путь к ffmpeg |

Остановка по Ctrl+C корректно завершает запись (контейнер дописывается).

## Возможности

- **Сцены**: создание, переключение (клавиши 1–5 или клик), удаление (нельзя удалить последнюю).
- **Источники**: цвет, текст (многострочный), изображение (PNG/JPEG), видеофайл (зацикливается, декодируется ffmpeg).
- **Расположение**: X/Y/ширина/высота, видимость, порядок слоёв (▲/▼). Источник нельзя «потерять» за край кадра.
- **Undo / Redo** для всех правок (Ctrl+Z / Ctrl+Shift+Z), переключение сцен в историю не попадает.
- **Проект**: сохранение (атомарная запись, Ctrl+S), загрузка с валидацией и миграцией версии 1 → 2. При попытке закрыть вкладку с несохранёнными правками браузер спрашивает подтверждение.
- **Запись**: MP4 (H.264), MKV (H.264) и WebM (VP9) через ffmpeg, Ctrl+R. Формат выбирается в панели инструментов.
- **Трансляция**: RTMP/RTMPS (FLV, H.264, битрейт 3 Мбит/с по умолчанию), Ctrl+Shift+S.
- **Статистика**: FPS, время отрисовки кадра, пропущенные кадры (по таймеру и по энкодеру), последняя ошибка.

## Горячие клавиши

| Действие | Клавиша |
|---|---|
| Сцена 1–5 | `1`–`5` |
| Запись старт/стоп | `Ctrl+R` |
| Трансляция старт/стоп | `Ctrl+Shift+S` |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Shift+Z` |
| Сохранить проект | `Ctrl+S` |
| Удалить выбранный источник | `Delete` |
| Сдвинуть выбранный источник на 1 px | `←` `→` `↑` `↓` |
| Сдвинуть на 10 px | `Shift` + стрелка |

Сочетания описаны в `src/hotkeys.js`. Реестр не даёт назначить одно сочетание двум действиям.
Браузер и сервер используют один и тот же модуль (`/shared/hotkeys.js`).

## API

Все команды идут через `POST /api/command` с телом `{"type": "...", "args": {...}}`.
Ответ: `{ok: true, result, project}` или `{error, code}` со статусом 400/422/500.

Основные команды: `scene.switch`, `scene.add`, `scene.remove`, `source.add`, `source.update`,
`source.move`, `source.remove`, `edit.undo`, `edit.redo`, `record.start`, `record.stop`,
`record.toggle`, `stream.start`, `stream.stop`, `stream.toggle`, `project.save`, `project.load`,
`project.set-canvas`, `status`.

Также: `GET /api/project`, `GET /api/preview.jpg`, `GET /api/hotkeys`. Статус — командой `status`.

## Структура

```
bin/studio.js          точка входа (аргументы, запуск, корректная остановка)
src/model.js           модель проекта, валидация, undo/redo (без I/O)
src/actions.js         слой команд: единая точка для API и UI
src/engine.js          таймер кадров, сборка кадра, выходы, статистика
src/compositor.js      отрисовка сцены (кэш слоёв и изображений)
src/encoder.js         ffmpeg для записи/трансляции (backpressure, коды ошибок)
src/media.js           декодирование видеофайла в RGBA
src/persistence.js     чтение/запись файла проекта
src/hotkeys.js         сочетания клавиш (общий для браузера)
src/server.js          HTTP: JSON API и статика
public/                интерфейс (HTML/CSS/JS без сборки)
test/                  тесты (node:test)
bench/                 замеры (bench.mjs, preview-bench.mjs) и их результаты
projects/demo.json     пример проекта
```

## Тесты, типы, замеры

```bash
STUDIO_FFMPEG=/путь/к/ffmpeg npm test          # 64 теста; часть использует реальный ffmpeg
npm run test:coverage                          # покрытие
npm run typecheck                              # tsc --checkJs --strict
npm run bench                                  # до/после отрисовки и реальная запись 10 с
node bench/preview-bench.mjs                   # стоимость JPEG-превью
```

Без `STUDIO_FFMPEG` (и без `ffmpeg` в PATH) тесты с ffmpeg **пропускаются** и это видно в выводе
(`# skipped`). Для полного прогона задайте переменную.

## Ограничения

См. раздел в `../docs/REPORT.md`. Кратко: нет захвата экрана, окна, камеры и звука;
нет переходов, фильтров, обрезки и поворота; RTMP проверен только на отказ подключения
(живого сервера в среде нет); интерфейс не проверен в настоящем браузере.
