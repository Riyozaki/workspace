# Exact tensor GP: воспроизводимый эксперимент ускорения

**Первичный, заранее зафиксированный результат: 11,54× на полном запуске процесса**
(95% seed-cluster bootstrap: **10,28–12,88×**, 15 пар = 5 наборов данных × 3 повтора).
Это **точная Gaussian-process регрессия на полной декартовой сетке с сепарабельным ядром**, а не ускорение произвольной нейросети.

- Baseline: **3,734 с**, метод: **0,324 с** в среднем, включая запуск Python, импорты, чтение входа, подготовку, fit, все 512 предсказаний **среднего и дисперсии**, метрики и запись результата.
- Held-out RMSE: **0,05668665433625** у обоих. Допуск **1e−7 absolute** зафиксирован до первого измерения; максимальное расхождение средних **2,55e−12**.
- Отдельный последующий аудит: NumPy-only вариант — **30,33×** против дополнительно оптимизированного dense-baseline. Это **не замена** первичного baseline и не пересчёт первоначальных результатов.
- Отдельные первичные пары дали **9,15–15,69×**. Не утверждается, что каждый запуск обязательно быстрее в 10 раз.
- Отдельное полное обучение гиперпараметров против sklearn GPR: **276,78×** [258,04–302,36], 10 пар, одинаковые optimizer evaluations/iterations и прошедшие quality guards.
- Все 12 естественных Set12-изображений: **22,51×** [22,16–22,91], **180/180** пар, PNG decode и подготовка включены. Это всё ещё специальная spatial-grid задача, не SOTA super-resolution и не независимое доказательство общего ускорения ИИ.
- Stress test сохранён полностью: **20 pass, 19 нарушений guards, 15 solver-failure пар**. Near-singular случаи не выдаются за lossless speedup.

## Одна команда

Из корня репозитория, Linux, Python 3.11+, интернет к PyPI и GitHub:

```bash
bash reproduce.sh
```

Создаёт `.venv`, устанавливает закреплённые версии, запускает тесты, все 15 первичных пар и полный четырёхвариантный аудит. На исходных 2 vCPU — примерно 3–5 минут. Все новые результаты находятся в **новой** папке `artifacts/reproductions/<UTC>/`; опубликованные результаты не перезаписываются.

Полное воспроизведение дополнительных исследований одной командой:

```bash
bash reproduce.sh --all
```

Включает scaling, пропуски в сетке, обучение гиперпараметров против **scikit-learn GaussianProcessRegressor**, все 12 внешних Set12-изображений и numerical stress test. Все эти исследования реально запускались отдельно; именно длинная интеграционная команда `--all` целиком повторно не прогонялась. Краткая команда выше проверена от начала до конца. Ориентир для `--all`, рассчитанный по отдельным этапам: 50–70 минут на сопоставимых двух CPU, до ~2,6 ГБ пикового RSS. На другом железе времена и ускорения **не гарантированы**. Историческая ошибка измерителя не воспроизводится: она исправлена и отдельно документирована.

Можно указать **новый, ещё не существующий** каталог вывода:

```bash
bash reproduce.sh --output /path/to/new/results
```

Зависимости закреплены в [requirements.txt](requirements.txt). Крупные временные файлы, входные изображения, предсказания и окружение исключены из Git; данные генерируются или скачиваются проверяемо. Внешний корпус закреплён по Git commit, blob SHA и SHA-256.

## Метод

При `K = Kx ⊗ Ky` и одинаковой дисперсии шума:

```text
Kx = Qx Λx Qxᵀ, Ky = Qy Λy Qyᵀ
D[i,j] = Λx[i] Λy[j] + noise_variance
H = Qxᵀ reshape(y - mean_train) Qy
W = H / D
```

Для произвольных **внесеточных** тестовых координат `t`:

```text
u = kx(t, Xx) Qx; v = ky(t, Xy) Qy
mean(t)     = Σij u[i] W[i,j] v[j] + mean_train
variance(t) = signal_variance − Σij u[i]² v[j]² / D[i,j]
```

Полный спектр, float64, без усечения ранга, distillation, подбора на test или изменения вероятностной модели. Подготовка собственных базисов включена в время. В точной арифметике это тот же posterior; в float64 эквивалентность проверяется измерениями и независимым sklearn reference.

**Это известная математическая идея, не заявление о новом открытии.** Реализация и эксперимент выполнены здесь; источники и ограничения указаны в отчёте.

Минимальное использование после установки зависимостей:

```python
from tensor_gp.spectral_numpy import NumpySpectralGP

# axes: [массив координат x, массив координат y]
# y: все значения на их декартовом произведении, C-order (y-координата быстрее)
offset = y.mean()  # только обучающие значения
gp = NumpySpectralGP().fit(axes, y - offset)
mean, latent_variance = gp.predict(test_coordinates)
mean += offset
```

## Ограничения — прочитать перед интерпретацией

1. Нужны полная декартова **обучающая** сетка, сепарабельное ядро и скалярный шум. Тестовые точки могут быть произвольными. Для произвольных облаков обучающих точек, Transformer/LLM или неразделимых ядер результат не доказан.
2. Первичный набор синтетический и структурный. Независимые изображения проверяют естественные значения целевой переменной, но **не устраняют** ограничение на структуру задачи. Это не data-agnostic 10× и не SOTA image-super-resolution benchmark.
3. На маленьких задачах запуск и импорты доминируют; 10× нет. На сетке 16×16 исходный метод даёт около 1×.
4. PCG-расширение с пропусками сохраняет качество, но оказалось значительно **медленнее** из-за сотен solves для posterior variance. Оно не используется для заявления об ускорении.
5. Near-zero noise ухудшает обусловленность; алгебраическая точность не гарантирует выполнение float64-допусков на любой задаче.
6. Fresh process ≠ очищенный файловый кэш. Виртуальная машина не эксклюзивная; интервалы характеризуют эти запуски, а не любое железо.
