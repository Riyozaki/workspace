# Хроники Этериума: Осколки Бездны (Книга первая, Главы 1–38)

Полная чистовая литературная редакция первого тома романа («Хроники Этериума: Осколки Бездны», 38 глав, 20 363 абзаца, 327 660 слов).

## Основные файлы в репозитории

- **`Хроники_Этериума_Осколки_Бездны_Книга_1_ПУБЛИКАЦИЯ.docx`** и **`Хроники_Этериума_Осколки_Бездны_редакция.docx`** — готовая к публикации чистовая рукопись в книжной вёрстке (`145×215 мм`, шрифт `Times New Roman 11 pt`, выключка по ширине, абзацный отступ `0,7 см`, межстрочный интервал `1,15`, активное оглавление с закладками `chapter1`–`chapter38`, автообновление полей нумерации страниц, язык документа `ru-RU` с автоматической расстановкой переносов).
- **`Глава_01_редакция.md` – `Глава_38_редакция.md`** — поглавные чистовые файлы в формате Markdown (100% поабзацная синхронизация с `.docx`).
- **`РЕВЬЮ_И_ГОТОВНОСТЬ_К_ПУБЛИКАЦИИ.md`** — итоговое редакторское ревью, сверка со старой редакцией (`хэ старая редакция.docx`), аудит имён собственных и канона, 12-балльная карта оценки и подробные синопсисы всех 38 глав.
- **`КАНОН_ПО_ТЕКСТУ.md`** — сквозная карта канона, персонажей, географии, механики вбирания и финансовых расчётов с точными индексами абзацев `[idx]`.
- **`ЖУРНАЛ_АНАЛИЗА_И_РЕДАКТУРЫ.md`** — полный журнал литературной, драматургической и стилометрической работы по всем 38 главам.
- **`редактура/проверка_рукописи.py`** — скрипт автоматической верификации `.docx` и `.md` (проверка целостности контейнера, закладок оглавления, синхронизации, отсутствия `;`, конструкций `не X, а Y`, предложений `>28` слов, предложений с `>=2 и`, соседних зачинов `«Я »` и оформления внутренней речи).
