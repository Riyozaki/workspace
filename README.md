# DistillPrune — ускорение инференса MLP в ~N× без потери качества (честный отчёт)

> Все числа в этом README заполнены из `results/` автоматически/вручную после измерений.
> Метки: **[ИЗМ]** — измерено, **[РАСЧЁТ]** — аналитическая оценка, **[ПРЕДПОЛОЖЕНИЕ]** — гипотеза.

## Что это

Метод **DistillPrune**: структурный прунинг нейронов обученного учителя по L2-норме исходящих
весов + дообучение узкого студента на soft-targets учителя (knowledge distillation, T=4, α=0.5).
Инференс — только плотный студент (без учителя, каскадов и кэшей).

- Baseline: MLP `784→1024→1024→10`, float32, Fashion-MNIST.
- Метод: тот же пайплайн, студент `784→W1→W2→10`, W выбирается по validation.
- Метрика качества: top-1 accuracy на официальном test (10 000 изображений).
- Допуск: средний парный разрыв ≤ **1.00 pp** и верхняя граница 95% CI ≤ 1.00 pp
  (зафиксировано в `PREREGISTRATION.md` до запусков).

## Воспроизведение одной командой

```bash
bash run_all.sh          # ~40 мин на 2 vCPU (grid baseline + 3 сида + test + бенчмарк)
```

Скрипт: создаёт venv, ставит numpy/scipy, скачивает Fashion-MNIST с официального GitHub,
запускает подбор baseline по validation, обучение учителей/студентов, заморозку выбора,
единственный прогон по test, бенчмарки латентности и сборку таблиц.

Дополнительные сиды 3–4 (для сужения CI) запускались отдельно:
`python experiments/train_all.py --seeds 3 --skip-controls` и то же для seed 4
(по 1 потоку BLAS на процесс, параллельно). Скорость измерялась на сидах 0–2.

## Результаты (кратко)

См. `report.md` (полный отчёт), `results/results.csv`, `results/summary.json`,
`results/timings.csv`, `results/test_metrics.csv`.

| | baseline | DistillPrune (160×96) |
|---|---|---|
| test top-1 (n=5) | 90.26% ± 0.20 | 89.56% ± 0.16 (**−0.70 pp**) |
| параметры | 1 863 690 | 142 026 (13.1× меньше) |
| FLOPs/sample | 3 723 264 | 283 520 (**13.13×**) [РАСЧЁТ] |
| латентность, batch 1024, P2 | 0.0221 мс/изобр | 0.0022 мс/изобр |
| **ускорение сквозного пайплайна (измерено)** | 1× | **10.14× ± 0.89** (n=3) |
| ускорение при явной нормализации (P1) | 1× | 6.97× (Amdahl) |
| стоимость обучения | 264 с | 301 с (1.14× дороже) |

**Честный вердикт:** критерий скорости (≥10×) выполнен; средний разрыв качества 0.698 pp ≤ 1.00 pp,
но верхняя граница 95% CI = **1.003 pp**, то есть строгий пре-регистрированный критерий
не выполнен на 0.003 pp. Подробности и все оговорки — в `report.md`, §5 и §7.
