# Итоговый отчёт: Studio — собственная реализация аналога OBS Studio

Ветка: `arena/365680e0-workspace`. Код: `studio/`. Журнал времени: `docs/TIMELOG.md`. Идеи: `docs/BRAINSTORM.md`.
Все утверждения ниже подтверждены командами; статусы: **сделано и проверено** / **сделано, не проверено** / **частично** / **не сделано**.

## 1. Что построено

Небольшое приложение «Studio» на Node.js + `@napi-rs/canvas` + ffmpeg:
сцены и источники (цвет, текст, изображение, видеофайл), расположение и порядок слоёв,
undo/redo, сохранение/загрузка проекта, запись MP4/WebM, RTMP-трансляция, веб-интерфейс с
предпросмотром, горячими клавишами и статистикой кадров. Без сборки фронтенда, без фреймворков.

Структура и запуск — см. `studio/README.md`. Размер кода: `wc -l studio/src/*.js studio/public/*`.

Честно о размере: это не полный OBS. Захват экрана, окна, камеры и звука в этой среде невозможен
(нет дисплея, устройств, аудиоподсистемы) и не реализован.

## 4. Найденные и исправленные дефекты (честный список)

1. **Картинки и текст пропадали в превью и записи.** Изображения сцены не подгружались при старте (`prepare` не вызывался). Найдено ручной проверкой кадра из MP4; исправлено `Engine.prepareActiveScene()`; проверено повторным извлечением кадра (логотип и текст есть).
2. **Базовый (наивный) режим рисовал без изображений.** Синхронный `Image` из `@napi-rs/canvas` не декодируется для `drawImage`. Найдено тестом паритета «кэш = базовый». Исправлено: базовый режим декодирует через `loadImage` каждый кадр.
3. **Отказавшая трансляция оставалась «активной».** Найдено тестом RTMP. Исправлено `watchOutput`.
4. **Подвешивание тестов** при падении (см. §3, п.9).
5. **`EADDRINUSE` выводил стек вызовов** вместо понятного текста. Исправлено.
6. **Нечётные размеры канваса принимались** и падали позже при записи. Исправлено в `project.set-canvas`.
7. **`record.stop` при отсутствии записи возвращал успех.** Исправлено (ошибка `not-recording`).
8. **Регрессия при исправлении п.3:** подписка на выход была привязана к заглушке. Поймано тестом RTMP; исправлено порядком вызовов.
9. **Сервер на 0.0.0.0 без авторизации** с произвольным чтением файлов. Исправлено по умолчанию (§3, п.5).
10. **Видеоисточник отсутствовал в типе `SourceKind`** (поймано `tsc`).
11. **MKV не записывался:** имя muxer'а ffmpeg — `matroska`, а не `mkv` (поймано тестом, код 234). Исправлено.
12. **CSRF-подобный вектор:** API принимал `text/plain` POST; страница из интернета могла отправить команду на `127.0.0.1:8080` через форму без CORS-проверки. Исправлено: только `application/json` (415), тест.
13. **Смена разрешения во время записи портила файл:** энкодер открыт с фиксированным размером кадра. Исправлено: `project.set-canvas` отвечает `busy` (тест).
14. **Пустое или нечисловое поле геометрии молча становилось 0.** Исправлено: ошибка `invalid` (тест).
15. **Добавление несуществующего файла** принималось и проявлялось только предупреждением в кадре. Исправлено: `file-not-found` сразу (тест).
16. **Отклонённая правка оставляла неверное значение в поле формы.** Исправлено: перерисовка из сохранённого состояния (в браузере не проверено автоматически).

## 8. Известные ограничения и недоделки

- **Нет захвата экрана/окна/камеры/звука.** В среде нет дисплея и устройств; в коде этого нет.
- **RTMP-отправка на живой сервер не проверена.** Проверено кодирование FLV и отказ подключения.
- **Браузерный интерфейс не проверен в настоящем браузере.** Нет браузера в среде. Проверены: отдача HTML/JS по HTTP, синтаксис, `tsc` для серверных модулей, визуальный результат через кадры записи и превью JPEG.
- **Браузер недоступен в среде.** Попытка установить Chromium через Playwright не удалась: CDN блокируется сетевой политикой песочницы (`Client network socket disconnected`). Поэтому интерфейс не проверен кликами и нажатиями клавиш.
- **Нет авторизации.** При `STUDIO_HOST=0.0.0.0` API открыт сети. Пути к файлам не ограничены каталогом проекта (любой путь, доступный процессу, можно указать).
- **Фильтры, студийный режим, масштабирование-режимы, плагины — не сделаны.** Переходы (затухание/выход), обрезка, поворот и прозрачность сделаны и проверены на уровне пикселей в тестах, но не проверены кликами в браузере.
- **Переназначение клавиш в интерфейсе не сделано** (реестр есть).
- **Бенчмарк запускается на одной машине (2 vCPU)**, разброс между прогонами ±10%.
- **Порог «10× по качеству» не достигнут в смысле OBS-паритета.** Улучшения измерены по отдельным осям (скорость отрисовки ×4–5, превью ×2.3, безопасность, типы, надёжность), но общий множитель не вычисляется и не заявляется.
- Редактирование сцен и источников доступно через UI, но панели настроек канваса/битрейта в UI нет.
